# SCODE-API-NODEJS

Is a npm Cli that installs a:

- NodeJs Api Server.
- React Admin backend
- React Site frontend

that you can modify, make your own and upload to your webserver.

=> Design, Development, DevOps

`npm install -g scode-website`

## Usage

`npx scode-website`
